Library Management System 
🎯 

A Python-based Library Management System built with OOP principles that allows users to manage books, accounts, and borrowing — with data saved in a JSON file for persistence.
✨ Key Features

    ✅ User login & account creation

    ✅ Borrow and return books

    ✅ View all books

    ✅ Track borrowed books

    ✅ Add books (Book / Novel / Magazine)

    ✅ Save & load data with JSON

    Main Classes
Class	Purpose
Book	Base class with title, author, year, is_borrowed, borrowed_by
Novel(Book)	Adds genre
Magazine(Book)	Adds issue
User	Handles login and borrowed books
Library	Manages books, users, and JSON save/load

🚀 Run

python main.py
 just run and enjoy! 🎉
